# Как открыть атлас с телефона

Сайт нужно разместить на HTTPS-хостинге один раз. После этого его можно открывать обычной ссылкой в Chrome на Android, независимо от запущенной облачной среды Codex. ZIP с исходниками не запускается как приложение на телефоне.

## Netlify — без терминала и слияния веток

1. Откройте **https://app.netlify.com/** и войдите через **GitHub**. Если аккаунта Netlify ещё нет, сервис предложит регистрацию.
2. Нажмите **Add new project → Import an existing project → GitHub**.
3. Выберите **DiRiK25/ak47-interactive-atlas**. Если репозитория нет в списке, откройте настройку подключения GitHub внутри Netlify и предоставьте сервису доступ именно к этому репозиторию. Пароли и токены в чат отправлять не нужно.
4. В поле **Branch to deploy** выберите **codex/ak47-museum-atlas**. Именно в этой ветке находятся готовый атлас и последние улучшения. Слияние в `main` для этого способа не требуется.
5. Оставьте **Base directory** пустым. Файл `netlify.toml` задаёт **Build command: npm run build**, **Publish directory: dist** и Node.js 24. Если форма предлагает заполнить поля вручную, скопируйте эти значения в соответствующие поля. Команду выполняет Netlify; телефон ничего не устанавливает.
6. Нажмите **Deploy project**. Дождитесь успешного статуса **Published** и откройте адрес проекта вида **https://имя-проекта.netlify.app**. Реальное имя выдаст Netlify; заранее созданной ссылки пока нет.

Это публикация сайта на Netlify. Она не включает GitHub Pages. Самостоятельная публикация из этой сессии Codex не выполнялась: вход в аккаунт хостинга остаётся за владельцем. После подключения репозитория Netlify обычно автоматически пересобирает сайт при новых отправках в выбранную ветку.

## Управление на телефоне

- Проведите одним пальцем по модели, чтобы повернуть её.
- Сведите или разведите два пальца для масштаба; также доступны кнопки «+» и «−».
- Коснитесь детали или откройте «Элементы», затем нажмите «Рассмотреть» в карточке.
- Четыре кнопки внизу переключают общий вид, внутренний обзор, экспозицию и фокус.
- В режиме экспозиции нажмите «Вернуть модель», чтобы собрать художественную композицию обратно.
- Кнопка со стрелкой возвращает исходную камеру. В настройках качества выберите «Низкое», если устройству тяжело отрисовывать сцену.

## Если вместо сайта ошибка

- Страница с README или ошибка отсутствия `package.json`: проверьте ветку **codex/ak47-museum-atlas** и пустое поле **Base directory**.
- Ошибка сборки: откройте журнал последнего Deploy и передайте в чат текст ошибки. Не вводите команды в терминале телефона.
- Адрес открывается, но нет модели: нужен современный браузер с WebGL2; попробуйте актуальный Chrome, перезагрузку страницы и кнопку повторного запуска экспозиции, если она показана.
