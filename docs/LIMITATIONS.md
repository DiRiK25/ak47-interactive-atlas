# Границы результата

- **Визуальная точность.** Это оригинальная художественная реконструкция внешнего образа АК Type 3. Не фотограмметрия, не скан и не атрибутированная копия конкретного музейного экземпляра. Называть её фотореалистичной или эталонно точной было бы неверно.
- **Исследование.** Запросы к музейным и справочным сайтам блокировались прокси (403). Исторические фотографии изучить не удалось. Журнал реальных попыток — `REFERENCES.md`. Обширное музейное исследование остаётся невыполненным пунктом исходного запроса.
- **Детали.** Пропорции, наружный крепёж, отделка дерева и металла, отдельные профили содержат художественные допущения. Масштаб условный. У поверхностей нет клейм конкретного экземпляра.
- **Внутренний обзор.** Три условных цветных объёма показывают общие области. Функционирующий механизм, боеприпасы, производственные данные и точная кинематика отсутствуют.
- **Экспозиция.** Смещения — художественная композиция. Это не последовательность разборки/сборки и не инструкция по обращению с оружием. На узком экране длинные подписи заменяются доступными маркерами; название читается в карточке или общем списке.
- **Прозрачность.** Прозрачные меши используют стандартную сортировку Three.js. На некоторых ракурсах пересекающиеся поверхности могут давать неодинаковую плотность; это ограничение способа схематичного отображения.
- **Телефоны.** Мобильная компоновка и касания проверяются в эмуляции Chromium. Проверка на физическом Android-устройстве, iPhone/Safari и разных мобильных GPU в облаке недоступна.
- **Производительность.** Частота кадров зависит от GPU и размера экрана. Облачный Chromium использует программный SwiftShader; его скорость не характеризует реальный телефон. Стабильные 60 FPS не заявляются. Авто уменьшает разрешение; «Низкое» отключает тени.
- **WebGL.** Нужен браузер с WebGL2. При его отсутствии или потере контекста доступно понятное сообщение и повторная попытка. Полноэкранный API поддерживается не всеми мобильными браузерами; альтернативой служит скрытие интерфейса.
- **Размер загрузки.** Three.js даёт отдельный JS-чанк около 526 КБ до сжатия, около 134 КБ gzip. Vite сообщает об этом предупреждением; это не ошибка сборки. Внешних моделей и крупных текстурных файлов нет.
- **Публикация.** Рабочая локальная сборка и файлы конфигурации не означают публикацию. Публичный HTTPS-адрес можно считать готовым только после фактического развёртывания у выбранного хостера.
